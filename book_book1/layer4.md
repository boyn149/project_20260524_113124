# Layer4: Action - Passive Attractive: ถอดรหัสเสน่ห์ลุ่มลึกฉบับผู้หญิง INFJ

* **Content Writing**
การเขียนเนื้อหาจะใช้รูปแบบ RWP (Rich Text with pic) เพื่อให้ผู้อ่านเข้าใจและเห็นภาพกลไกการสร้างเสน่ห์ของ INFJ ได้อย่างชัดเจน โดยมีแนวทางการเขียนดังนี้
    * ใช้ **ตัวหนา (Bold)** เพื่อเน้นย้ำจุดสำคัญและแก่นของทฤษฎี (เช่น ชื่อฟังก์ชัน MBTI หรือกลยุทธ์สำคัญ)
    * ใช้ *ตัวเอียง (Italic)* เพื่อเน้นความหมายของคำศัพท์เฉพาะทางจิตวิทยาหรือคำเฉพาะจาก Art of Seduction
    * ใช้ Bullet / List เพื่อจัดเรียงข้อมูลให้เป็นระเบียบ ทำให้อ่านง่ายและจับใจความได้เร็ว
    * แทรก ตาราง (Table) เพื่อเปรียบเทียบข้อมูลให้เห็นความแตกต่างที่ชัดเจน เช่น การเปรียบเทียบระหว่างการเป็นฝ่ายรุก (Active) กับการดึงดูดแบบไม่ต้องพยายาม (Passive)
    * ใช้ Callout Box (CB) แบบมีไอคอน เพื่อเน้นกรอบข้อความสั้นๆ ที่เป็นข้อควรระวัง จุดสังเกต หรือบทสรุปสำคัญในแต่ละหัวข้อ

* **Visual**
การใช้ภาพประกอบเพื่อส่งเสริมการเรียนรู้และเสริมความเข้าใจในเนื้อหา โดยมีแนวทางดังนี้
    * **รูปภาพแทรกเนื้อหา:** ให้แสดงคำสั่งเป็นภาษาอังกฤษในรูปแบบ `[PROMPT: ...]` สำหรับนำไปสร้างภาพ โดยกำหนดอัตราส่วนภาพที่ 16:8 สไตล์ Minimal และใช้พื้นหลังสีขาว เพื่อให้ภาพดูสะอาดตาและสื่ออารมณ์ความลุ่มลึกได้ดี
    * **Educational Infographic:** ใช้ภาพอินโฟกราฟิกเพื่อสรุปกระบวนการหรือความรู้ที่ซับซ้อน โดยระบุ Prompt เป็นภาษาอังกฤษ แต่โครงสร้างและข้อมูลในภาพจะเป็นภาษาไทย รูปแบบอินโฟกราฟิกที่เลือกใช้ได้แก่:
        * *Informational Infographic:* สำหรับอธิบายการทำงานของ Ni และ Fe
        * *Process Infographic:* สำหรับแสดงลำดับขั้นตอนการประยุกต์ใช้กลยุทธ์ดึงดูด
        * *Grid Infographic:* สำหรับแยกประเด็นข้อดีข้อเสีย หรือการจับคู่สไตล์ต่างๆ
        * *Hierarchy / Pyramid Infographic:* สำหรับแสดงระดับความสำคัญของการรู้เท่าทันตนเอง (Self-awareness) จากฐานไปสู่ยอด
