# Layer4: Action - เมื่อฟางเส้นสุดท้ายขาดลง: เข้าใจกลไกการ Door Slam ของ INFJ

* **Content Writing**
การเขียนเนื้อหาจะใช้รูปแบบ RWOP (Rich Text without pic) อย่างเคร่งครัด โดยเน้นไปที่การอธิบายความซับซ้อนทางอารมณ์และกระบวนการทางจิตวิทยาให้อ่านเข้าใจง่าย มีน้ำหนัก และน่าติดตาม โดยมีแนวทางการจัดรูปแบบเนื้อหาดังนี้
    * ใช้ **ตัวหนา (Bold)** เพื่อเน้นจุดสำคัญ แก่นของเนื้อหา หรือระดับสภาวะอารมณ์ที่รุนแรงขึ้น 
    * ใช้ *ตัวเอียง (Italic)* เพื่อเน้นความหมายของคำศัพท์เฉพาะทางจิตวิทยา กลไกการทำงาน หรือคำเฉพาะทาง MBTI (เช่น *Door Slam*, *Introverted Intuition*, *Extraverted Feeling*)
    * ใช้ Bullet / List เพื่อจัดเรียงข้อมูลกระบวนการทางความคิด สัญญาณเตือน หรือขั้นตอนการตระหนักรู้ให้เป็นข้อๆ เพื่อให้ผู้อ่านจับใจความและสำรวจตัวเองได้ง่าย
    * แทรก ตาราง (Table) เพื่อใช้ในการเปรียบเทียบหรือสรุปข้อมูลที่ซับซ้อน เช่น การเปรียบเทียบการแก้ปัญหาความสัมพันธ์แบบปกติ กับ การใช้กลไกป้องกันตัวแบบ Door Slam หรือเปรียบเทียบฟังก์ชันการทำงานที่อยู่ในสภาวะปกติและสภาวะเครียดสะสม
    * ใช้ Callout Box (CB) แบบมีไอคอน เพื่อเน้นกรอบข้อความสั้นๆ เช่น ข้อควรระวังในการรักษาความสัมพันธ์ จุดสังเกตอารมณ์ของตนเอง หรือข้อคิดสรุปประจำหัวข้อ

* **Visual**
เนื่องจากหนังสือเล่มนี้มีข้อกำหนดชัดเจนในการใช้โครงสร้างแบบ RWOP และ **ไม่มีรูปแทรก** จึงจะไม่มีการเขียน Prompt ภาษาอังกฤษเพื่อสร้างภาพประกอบ รวมถึงไม่มีการใช้อินโฟกราฟิกใดๆ ทั้งสิ้น 
การออกแบบภาพรวมของการอ่าน (Visual Layout) จะพึ่งพาการจัดรูปแบบตัวอักษรและการวางโครงสร้างข้อความเท่านั้น โดยจะเน้นการใช้พื้นที่ว่าง (White Space) การแบ่งย่อหน้าให้พอดี การใช้ตาราง และกรอบข้อความ Callout Box เป็นจุดพักสายตา เพื่อลดความหนาแน่นของเนื้อหาเชิงจิตวิทยา และทำให้ผู้อ่านสามารถซึมซับข้อมูลเชิงลึกได้อย่างสบายตาและเป็นระเบียบ
